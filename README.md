# Разбивка ГВС — расчётный инструмент

Внутренний веб-инструмент ОАО «БПА БЕЛСТРОЙИНДУСТРИЯ» для разбивки тепловой
нагрузки ГВС между ступенями в двухступенчатой смешанной схеме подключения.
Полностью повторяет формулы листа «Методика» файла
«Разбивка ГВС для 2-х ступ. смеш..xls».

Статический сайт: чистые HTML/CSS/JS, без сервера, без сборки, без внешних
библиотек и без базы данных. Открывается прямо из файла или с любого
статического хостинга (см. «Публикация на GitHub Pages» ниже).

## Как запустить локально

Файлы можно открыть прямо в браузере (`index.html` двойным щелчком) —
скрипты подключены через `<script src="...">`, без `fetch`/модулей, поэтому
`file://` работает без локального сервера. Google Fonts подключены с CDN;
без интернета применяется системный шрифт-заместитель (в стилях уже
прописаны бесшрифтовые запасные варианты).

Если удобнее через локальный сервер (например, чтобы протестировать печать
без предупреждений браузера про `file://`):

```bash
cd gvs-calc
python3 -m http.server 8000
# затем открыть http://localhost:8000/
```

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы, подключение стилей и скриптов |
| `style.css` | все стили, включая тёмную тему и стили печати |
| `calc.js` | чистый расчётный модуль — формулы строки 14 листа «Методика» |
| `units.js` | конвертация единиц мощности/расхода |
| `format.js` | форматирование чисел (фиксированное число знаков, точка как разделитель) |
| `solver.js` | автоподбор E14 методом бисекции (режим «Автоматический») |
| `validate.js` | проверка физической осмысленности исходных данных |
| `scheme.js` | отрисовка SVG-схемы (чистая функция, строка разметки на выходе) |
| `zip.js` | минимальный писатель ZIP-архивов (метод STORED, без сжатия) |
| `export-docx.js` | сборка отчёта в формате .docx (OOXML) поверх `zip.js` |
| `app.js` | связывает всё перечисленное с DOM: состояние, обработчики, рендер |
| `calc.test.js` | модульные тесты (без внешнего фреймворка) — `node calc.test.js` |

Каждый модуль расчёта/форматирования/схемы/zip написан в одном и том же
двойном формате — работает и в браузере (вешает себя на `window.GVS`), и в
Node через `module.exports` — это и позволяет гонять `calc.test.js` напрямую
командой `node`, без сборки и без браузера.

### Почему нет вендор-библиотек

В плане разработки в качестве единственной внешней зависимости
предполагался Alpine.js — от него отказались в пользу обычного
vanilla JS: расчёт и без того простой (один `render()` на изменение поля),
а нулевая зависимость проще поддерживать без сборки.

Экспорт в DOCX тоже сделан без внешних библиотек: `.docx` — это ZIP-архив
с несколькими XML-файлами внутри (OOXML), и для десятка простых бинарных
структур ZIP (см. `zip.js`) внешняя библиотека — лишняя зависимость, а не
экономия. Проверено: полученный файл проходит `unzip -t`, XML внутри
валиден и открывается в Word/LibreOffice без предупреждений.

## Тесты

```bash
node calc.test.js
```

Проверяются: совпадение с базовым примером из методики (U14 ≈ 29.96 °C),
устойчивость к делению на 0 и к граничным значениям, конвертация единиц
туда-обратно, автоподбор E14 (включая недостижимую цель), правила
валидации, форматирование чисел и сборка .docx (структура ZIP + валидность
XML внутри).

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub (публичный — на бесплатном плане Pages
   работает только с публичных репозиториев; приватный потребует платный
   план).
2. Загрузить в него содержимое этой папки (`git push` или загрузка файлов
   через интерфейс GitHub).
3. В настройках репозитория → **Settings → Pages** выбрать источник
   **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через несколько минут сайт будет доступен по адресу вида
   `https://<аккаунт>.github.io/<репозиторий>/`.

Обновление сайта — обычный `git push` в ту же ветку; Pages пересобирает
статику автоматически, без дополнительных действий.

## Что не входит в инструмент

Подбор конкретной модели теплообменника — только разбивка тепловой
нагрузки ГВС между ступенями. Печать в PDF — через диалог печати браузера
(кнопка «Печать / PDF»), отдельного PDF-движка нет.
